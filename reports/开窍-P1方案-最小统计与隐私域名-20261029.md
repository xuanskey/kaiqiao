# 开窍 P1 方案：最小统计与隐私、域名（2026-10-29）

本文只提出方案；没有添加统计代码、端点、页脚隐私文案、备案号或域名跳转，没有操作 Cloudflare。价格与能力查阅下列官方文档，实施前须再次确认账户实际套餐和当时额度。

## 最小统计的选择

目标是回答「有多少次访问、多少次进入、常选哪个年级、有没有开始课/完成随堂、有没有点击备份」，只看聚合次数，不识别个人，不做跨页用户串联、留存追踪或精确用户转化漏斗。

| 方案 | 能力和边界 | 成本与限制 | 判断 |
| --- | --- | --- | --- |
| Cloudflare Web Analytics | 访问与性能统计，无自定义事件；JS beacon 是第三方脚本，不能满足本任务的无第三方脚本约束；用路径伪装点击会污染页面访问数据 | 官方提供免费服务 | 仅比较，不推荐开启或注入 |
| 同源 POST `/e` → Workers Analytics Engine | 本站代码发固定枚举事件，Worker 白名单校验后写点，查询只返回日期/事件/年级聚合；无个人字段 | 官方表列 Free 每天 100,000 写点、10,000 查询；页面同时注明当前暂不计费、未来启用所列价格。Worker 请求另计，共享 Free 每天 100,000 请求；超过免费额度停止接收，不自动升级。AE 默认保留三个月 | 推荐作为以后的小试验；底层仍存最小事件点，不能宣称「数据库仅有聚合行」 |
| 同源 `/e` → 仅聚合 KV 计数 | 只存「日/事件/年级 → 次数」；KV 读改写非原子，并发会丢数，同一个键写入限速，不可直接每事件递增作为准确计数器；内存攒批也可能随 isolate 回收丢失。要准确需再评估串行聚合设施 | Free：100,000 键读取/日，1,000 键写入/日、1 GB；同键最多 1 次写/秒。看似省空间，持续事件上报很容易撞写额度 | 只适合明确接受近似数、低流量的验证，或另行批准可靠聚合设计 |

来源：[Web Analytics 免费说明](https://www.cloudflare.com/web-analytics/)、[不支持自定义事件的 FAQ](https://developers.cloudflare.com/web-analytics/faq/)、[Analytics Engine 价格](https://developers.cloudflare.com/analytics/analytics-engine/pricing/)、[保留期](https://developers.cloudflare.com/analytics/analytics-engine/limits/)、[Worker 价格](https://developers.cloudflare.com/workers/platform/pricing/)、[KV 价格](https://developers.cloudflare.com/kv/platform/pricing/)、[KV 限制](https://developers.cloudflare.com/kv/platform/limits/)。

推荐先批准小规模同源 `/e` + AE，观察两周。只显示总次数和年级分布，不做孩子画像。若杨哥要求持久层只保留聚合数，应改选经过并发验证的聚合设计后再开工，不能把 AE 的逐点存储说成仅聚合存储。

## 事件和字段（未来实施）

| 事件枚举 | 触发口径 | 来源 |
| --- | --- | --- |
| `visit` | 首页每次文档加载一次；练习壳与 iframe 不重复记访问 | 主站 |
| `enter` | 点击两个主按钮或导航练习链接一次 | 主站，年级入口单独记 grade_select |
| `grade_select` | 首页年级直达点击；应用中用户主动切换年级另计，不重复记录初始化 | 主站或应用 |
| `lesson_start` | 用户打开一节互动课时一次；重渲染、自动讲解步骤不计 | 应用 |
| `quiz_complete` | 完成一轮随堂练习并结算一次；最后一题重复提交不重复计 | 应用 |
| `backup_export_click` | 点击现有「学情 → 导出备份」；只代表点击，不保证下载或备份成功 | 应用 |

请求体仅 `v:1`、`event:固定枚举`、`surface:home/app`、`grade:1..6或null`、`count:1`。服务端生成北京时间日期 `day`；AE 自带时间戳，业务查询只按天呈现。不要传课程名称、题干、答案、正确率、孩子姓名、设备 ID、用户 ID、UUID、完整 URL/query、referrer、IP、UA、位置、AI 配置或备份内容。课程事件最初不分 lessonId，以减少维度。允许页内临时防重复标志，不写标识 cookie/localStorage，不跨会话去重，所以次数不等于人数。

端点只接受同源小体积 POST、固定字段与枚举，`credentials:omit`、`referrerPolicy:no-referrer`；不把请求 headers、IP/UA 或正文写日志，不启用含请求详情的 Observability/Logpush。Origin 校验、请求体大小/枚举验证与全局预算限额只能缓解误用，不能当作可信身份鉴权；无需 IP 限流或指纹。响应 `204`，失败不阻塞学习、不补发离线历史、不进 SW 缓存、不累积重试；提供总开关。允许丢失数据，说明拦截器、离线、刷量、重载及采样造成偏差。

隐私口径：「只统计每日访问与操作次数及年级分布，不收集姓名、题目答案或备份内容，不设置跟踪标识，不记录 IP/UA。」必须说明这约束的是业务统计；网络传输与 Cloudflare 基础服务仍能接触连接 IP/请求头，不能承诺互联网传输中不存在这些信息。数据只让管理员看聚合结果；AE 自带三个月保留期，暂不再存额外导出明细。

需要杨哥明确授权后才能做：确认统计目的、字段、保留期与隐私措辞；批准未来修改应用中的三处事件触发（本轮不改 src）；批准创建 Worker、数据集和 binding、设置同源路由；核查账户套餐/计费状态，批准预算与超额关闭方式；设置管理员访问权限、服务端查询凭据（不进入前端/仓库）；审批预览验证与上线。涉及部署、Cloudflare 设置和域名跳转的步骤另行授权。本轮均未实施。

## 页脚隐私一句建议（本轮不改页脚）

建议：「默认不向第三方发送学习数据，记录仅保存在当前浏览器；请定期在『学情』导出备份，主动使用联网 AI 等功能时按所选服务处理请求。」

依据：主站 `index.html`、`app.js` 与资源均同源，专项 Chromium 检查拦截并断言默认路径无非同源请求；`src/lib/lesson/ai.ts` 的 `DEFAULT_AI.enabled=false`，`askAi` 在未启用或无密钥时直接返回，启用后才向家长配置地址请求；`src/components/lesson/ai-panel.tsx` 默认模式为 own，切换 platform 后才获取余额，`src/lib/lesson/platform-ai.ts` 使用同源 `/api/ai/*`，未来服务器可能再调用外部 AI。OCR 模型本地同源，非第三方 CDN。代码排查与本地浏览器结果不能替代生产边缘自动注入核查；上线前还需检查 Pages 是否自动注入 beacon。这里「零外发」指默认无非同源后台请求，正常同源资源下载仍发生，用户主动点外部教材链接也会离站。

## www 与 canonical 统一检查清单（只列计划）

以现有 `https://www.yanghat.cn/` 为候选统一源，域名决定由杨哥确认。此轮保持 PR#21 SEO 原值。

- [ ] canonical：首页、应用壳及实际可索引页面分别核查，练习参数是否需要独立 canonical 另定，不能误改入口参数。
- [ ] `og:url` 与首页 canonical 相同。
- [ ] `og:image`、`twitter:image` 使用统一源和现有带版本分享图，实测 200、尺寸与缓存。
- [ ] JSON-LD 中存在的 url/@id（含未来新增类型）统一源；FAQ Answer 链接用真实 HTTPS 公共入口。当前 FAQPage 没有顶层 url，不臆造已存在字段。
- [ ] sitemap 中 loc 使用统一源、只列真实可索引页面。
- [ ] robots 的 Sitemap 地址使用统一源，确认应用缓存路径不被误处理。
- [ ] 页内绝对链接、文档中的正式入口逐项盘点；相对同源链接保持参数和锚点。
- [ ] 裸域跳转需要另行授权设置 Cloudflare 重定向规则，保留路径、query（practice/grade/lesson）和避免循环；分别验证 HTTP/HTTPS、裸域/www、课程直达与下载。
- [ ] 迁移期提醒 localStorage 按源隔离：先在原源的「学情 → 导出备份」，再在目标源恢复；不要提前封死旧源导出入口。切换域名还须核查两个作用域的 service worker 与离线入口。
- [ ] 预览核对 SEO/缓存/全部年级直达，再经批准上线；上线后用真实响应检查边缘规则与自动注入。
