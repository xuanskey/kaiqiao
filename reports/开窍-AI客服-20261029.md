## 设计与理由

- Pages Function `/api/help` 调用无依赖 ESM 模块；唯一其它函数路由仍为 `/e`。复制 metrics 的同源和 host 白名单逻辑，没有改 metrics handler 或入口。
- 顺序检查 POST、同源/host、JSON 媒体类型、2048 UTF-8 字节、JSON 普通对象与严格 q/v 协议。问题 trim 后按码点计 1–300。错误为空 body；所有响应 no-store/nosniff/no-referrer，不设置跨源或会话头。
- 输入先替换邮箱、手机、座机、身份证、账号、长数字、常见地址、姓名和学校。普通算式和「第3单元」「第13单元」保留。正则无法保证识别所有个人信息，因此界面明确提醒不要填写。
- 中文系统提示词 696 字（测试限制 ≤1200 码点），覆盖开始练习、选择练习年级、学情、备份与恢复真实入口、充值说明、反馈邮箱、隐私及许可；数学只提示思路。充值说明集中在 `workers/help/prompt.js` 的 `TOPUP_GUIDANCE` 常量：手动充值页上线前只说「即将上线、请家长操作、有问题发邮件 hello@yanghat.cn」，不写任何价格；上线该页的 PR 只需改这个常量及其测试。单轮 deepseek-flash（thinking disabled，非思考模式），max_tokens 300，temperature 0.3，15 秒 AbortController 超时。返回文本按既有 sanitize.ts 规则去代码块、HTML、URL、markdown 符号，最多 600 字；两端均以纯文本渲染。
- 缺 key/DB 提前兜底，不触碰数据库或上游。D1 异常 fail closed；限额和上游异常均用固定儿童友好文案，不包含上游错误或主动回显问题。
- D1 仅存 help_spend(day TEXT PRIMARY KEY, micro INTEGER NOT NULL)，北京时间日期、整数微元。每日硬上限 1,000,000 微元（1 元），不读可调额度环境变量。一次 batch 建表并原子预留；INSERT 使用 SELECT ... WHERE ?2 <= ?3，保证首次插入同样受上限约束，冲突更新使用 WHERE micro + ?2 <= ?3 RETURNING micro。
- 预留 `(UTF-8字节数(system+净化问题)+64)*2+300*8`。usage 按未命中 2、命中 0.04、输出 8 微元/token 向上取整；缓存字段缺失时全算未命中。2xx 有有效 usage 时退补差额；非 2xx 全退；超时/网络/无有效 usage 保留预留；结算失败吞掉，保守不扩大额度。
- 不读取或存储 IP、User-Agent、Cookie、Referer、request.cf、用户 ID、提问或聊天。help 源文件及入口由单测和打包扫描强制检查禁用词、禁止 console；测试文件也纳入扫描。
- 唯一客户端开关 VITE_HELP_ENDPOINT，仅空值或 `/api/help`，release 和 Vite 构建均校验。默认不建首页帮助 DOM，应用组件返回 null，零帮助请求。首页 practice=1 不重复显示入口。请求 omit credentials、no-referrer、no-store；关闭或 Escape 清空问答并取消请求，不使用浏览器存储。

## 风险与限制

- 无按人限速。非浏览器可伪造同源头，恶意刷量可能提前耗尽当日 1 元预留额度，只影响帮助功能。管理员可另评估 Cloudflare WAF 限速规则，本任务不配置。
- PII 正则不完备，可能漏报或误报；提示词不能保证模型完全遵守范围，模型可能答偏或提示过时，界面标注「AI 回答，仅供参考」。不把提示词当安全隔离边界。
- 请求经过 Cloudflare 和 DeepSeek，基础网络服务可见连接信息；本模块不读取或存储这些信息，不能承诺供应商网络层不可见。界面禁止输入个人信息，发送前净化。
- D1 免费额度包括读取、写入和存储限制；仍需管理员确认目标账号实际额度。Functions 免费额度通常为 10 万次/天，与 Workers 共享；应确认超额行为和静态站可用性。本次未查询或更改生产配额。
- 固定价格与字节预留是保守模型，供应商可能改价；应人工复核价格和 token 上界假设。超时/网络/usage 缺失/结算失败均可能让本地累计高于实际花费，降低当日可用次数。
- 表按天累积且没有清理旧日期；只含日期/聚合整数，但长期仍需留意 D1 存储额度。
- D1 或 Functions 故障不影响静态练习逻辑，但可能使帮助不可用。应用既有其它 AI 功能与隐私文案未修改，不属于本任务客服接口。
- Vite 原有 >500 kB chunk 警告保留，未顺手调整拆包。
