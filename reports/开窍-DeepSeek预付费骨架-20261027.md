## 本地运行（Node 24）

```sh
export PATH=/tmp/node-v24/bin:$PATH
# 终端 1：令牌仅用于本机演示，实际使用请自行替换
MOCK_DEEPSEEK=1 AI_ADMIN_TOKEN=local-demo-only npm run mock:ai
# 终端 2
npm run dev
```

访问 Vite 页面，在课堂 AI 服务中选「平台 AI（预付费）」。默认余额为零；复制显示的本机账户编号，人工加点后点击刷新余额：

```sh
curl -X POST http://127.0.0.1:8787/api/ai/topup \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer local-demo-only' \
  -d '{"accountId":"替换为页面账户编号","amountFen":100}'
curl 'http://127.0.0.1:8787/api/ai/balance?accountId=替换为页面账户编号'
curl -X POST http://127.0.0.1:8787/api/ai/ask \
  -H 'Content-Type: application/json' \
  -d '{"accountId":"替换为页面账户编号","ask":"如何理解这道题？"}'
```

1 分 = 1 点。单次 mock 固定 usage 为 prompt 120、completion 60、cached 20，按给定费率计算后最低扣 1 点。前端同源 `/api/ai/*` 由 Vite 代理到仅监听 127.0.0.1 的本地服务。重启服务余额和账本全部清空。未设置管理员令牌时充值接口拒绝所有充值请求。

独立自测：`PATH=/tmp/node-v24/bin:$PATH npm run test:ai`。测试不依赖监听端口，通过标准 Request/Response 验证 API。上游默认 `MOCK_DEEPSEEK=1`；设置 0 也只会拒绝调用，代码没有真实上游 fetch。平台模型配置固定 deepseek-flash、thinking disabled、max_tokens 400、超时 20s；mock 不生成真实模型请求，前端请求设 20s 超时。

## 当前边界与生产建议

- 这是本地 mock 骨架，账户 UUID 仅演示标识，**不是身份认证**。不能把此内存服务直接当生产账本。真实部署前需服务端会话/设备凭证校验与账户绑定、恢复流程。
- 建议 Worker + Durable Object 或事务数据库账本；扣点、预留、结算、退款、充值需原子事务、审计、幂等键与重放保护。当前请求中每账户互斥避免 mock 并发透支，失败不扣点；真实上游要先按最大输入与输出预留费用再结算，不能只检查最低 1 点。
- 目前只实现管理员令牌人工加点；充值码生成、一次性核销、发放台账、对账、退款与运营流程仍待完成。不接微信/支付宝。
- 真密钥测通仍须单独批准；尚无真实上游实现。后续需核对实际 usage、费率和费用；法定节假日日历尚未接入，当前接口只按工作日时段判峰谷。
- Worker secrets 尚未配置（未来 `DEEPSEEK_API_KEY`、管理员密钥），均不得下发浏览器。还需服务端消息构建、输入校验、安全纯文本净化、20s 超时和 400 token 上限的真实请求约束。当前 mock 返回固定安全纯文本，前端还会净化显示内容。
- 家长自备密钥路径保持并存、费用由家长自行承担；本次自测未调用该真实网络路径。iOS/Capacitor 壳没有修改，平台入口的原生环境隔离应在将来接壳时另行验收。本期不合并 PR #18。
