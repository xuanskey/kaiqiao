# 开窍

适合家长陪练的小学数学网页工具。先选年级，再完成一组练习；答错时看解析、做同考点巩固，最后导出学情。

覆盖一至六年级的部分基础题型。现有 52 个出题模块、18 个三年级原创知识单元，以及“互动课堂”（21 个数学演示、11 个科学实验）；教材版本、学期与目录尚未逐项核对，不能当作完整教材同步。

## 使用

正式入口：[开窍在线练习](https://kaiqiao.yanghat.cn) · [养习主站](https://www.yanghat.cn)

第一次使用请看[使用指南](USAGE.md)：按年级选择题库，三年级可从理解实验开始；包含操作、计分、备份迁移和问题反馈方法。

下载新版发布包，解压后直接打开 `offline.html`。也可以把 `docs/` 部署到静态网页服务，访问 `index.html`。旧版下载包不会自动升级。

1. 首页选择练习年级；切换年级不会删除其他年级进度。
2. “题库”支持按知识点直接练习，提供基础/进阶两组及本年级搜索；也可切换原有闯关路线。首页可选“开始每日练习”或“开始闯关”。普通练习看完解析后点“下一题”；答错的题会安排同考点巩固。
3. “90 秒小挑战”是限时练习，“和窍窍比一比”的对手是电脑。限时模式会自动换题，可在错题本慢慢复习。
4. 错题本只显示当前年级；原题答对后移出。每个年级的章节独立解锁。
5. “理解”进入原创知识单元：先读情境和讲解，操作实验，再做 8 题练习或 12 题自测。自测固定题数，两种模式均逐题反馈。
6. “学情”汇总当前浏览器所有年级的已答题，支持文字报告和 JSON 备份；完成单元后还可导出家长建议。

## 数据与计分

- 不需要账号。记录仅保存在当前浏览器，不自动同步，也没有服务器收集孩子信息。
- 同一设备不同浏览器、网址或离线文件，可能使用不同的存储空间。更换前先导出备份，在新环境恢复。
- 恢复备份会替换所有年级的本机记录，先预览，再确认；不合并记录。
- 每次提交即保存答题、错题和技能统计。退出未完成练习不计通关、经验或打卡。
- 通关/每日整组完成，或限时结束且至少答过一题，才计打卡。未作答不算完成。
- 学情包含复习作答和未完成练习中的已答题，不等同于考试成绩。
- 浏览器禁用存储或存档损坏时会明确提示，不静默覆盖损坏的原存档。建议定期备份。
- 一个浏览器存档适合一名孩子；暂不提供多孩子账号隔离。

## 本地开发

使用 Node.js 24 或更高版本。

```bash
npm ci
npm run dev
```

```bash
npm run check       # 类型检查 + 回归测试 + 生产构建
npm run release     # 生成 docs/ 网站目录与 offline.html 单文件版
```

- `src/lib/math/`：题目、判分、存档校验和回归测试。
- `src/store/math.ts`：练习状态、年级和结算。
- `src/components/math/`：首页、练习、错题、学情及电脑/手机自适应界面。
- `docs/`：可部署的构建产物；每次发布通过脚本重新生成。

## 当前边界与试用方向

目前没有支付、会员、OCR、在线老师或多人实时对战功能。题目由规则生成，不调用付费 AI API。朗读依赖浏览器支持。

先邀请少量家长试用，记录是否愿意连续使用、哪些解析看不懂，再验证“练习计划 + 人工解读报告”的付费服务。具体流程见 [PILOT.md](PILOT.md)。收入尚未验证，不承诺提分。

## v0.10.0 新首页、多格式导入、语音朗读

- **全新首页**：按时间问候和日期；“今天的学习计划”把一天拆成三步（上一节互动课 → 每日练习 → 错题回顾），进度环显示完成几步，下一步高亮；“今日推荐”每天自动轮换一节本年级的数学互动课和一个科学实验，点一下直接进课；底部统计新增“课堂练习题数”。手机和电脑都重新排版。
- **资料导入支持更多格式**：PDF（读取可复制的文字，最多 30 页）、Word（.docx）、PPT（.pptx，按页读取）和图片/拍照识别（中文 + 英文）。旧版 .doc/.ppt 会提示另存为新格式；扫描版 PDF 会提示改用截图识别。只读取文字，不执行文件里的宏或脚本。
- **按需加载**：PDF、Word、PPT 解析组件和拍照识别组件都只在选择对应文件时才下载，不影响首页打开速度，也不进离线预缓存。拍照识别的组件和模型放在本站 `/ocr/` 目录，不依赖境外 CDN。
- **语音朗读**：课堂里勾选“语音朗读老师的话”，每一步自动读出老师的讲解；暂停时停止，离开课堂时停止（使用浏览器自带的中文语音，不联网、不上传）。
- 离线版 `offline.html` 只内嵌首页入口脚本，修正了多个脚本文件时可能内嵌错文件的问题。

## v0.9.0 科学实验扩充

新增 6 个科学互动实验，教科版科学目录扩展到三下、四上、四下、六上：

- **杠杆的科学**（六上·工具与技术）：调阻力、阻力点和用力点的格数，按“钩码数 × 格数”平衡条件计算用力，判断省力、费力；可直接点刻度移动用力点。
- **斜面的作用**（六上·工具与技术）：改变物重、斜面高和长，按理想斜面计算拉力，说明“坡越缓越省力、省力不省距离”。
- **声音的高低和强弱**（四上·声音）：改变拨钢尺的力度和伸出长度，看振幅和振动快慢的波形，区分响度和音调。
- **昼夜交替与地球自转**（六上·地球的运动）：拖动时间看北京在白天还是黑夜、太阳在哪个方向（按春分前后简化）。
- **摩擦力的秘密**（四上·运动和力）：换玻璃、木板、毛巾表面、加钩码，看测力计读数（整数计算，无浮点误差）。
- **绿豆种子发芽和生长**（三下、四下·植物的生长变化）：改变水分、光照和天数，看发芽条件和豆苗高度、叶色。

每个实验都有实验目的、器材、步骤、观察、解释、安全提醒、思考题和“虚拟模拟与真实实验的区别”，配随堂练习（独立重算核对）、生活例子和资料导入关键词。

## v0.8.0 互动课堂

新增“课堂”入口：按年级（1—6）、上下册、学科（数学/科学）、教材版本和单元选课，打开带动态板书的互动课。

- **课程目录**：默认“人教版（2024 新版）”，按 2026 年秋季使用的新课本目录整理：六上为确定位置、分数乘除法、生活中的负数、圆、百分数、鸽巢问题等，不再有比、扇形统计图、数与形；五上为“用字母表示数和数量关系”，解方程已调整到初中；四上新增加法模型和乘法模型、寻找宝藏。新版四、五、六年级下册 2027 年春季才启用，这学期界面会明确提示并显示旧版目录。另保留“人教版（2012 旧版）”目录供对照；教科版科学只收录有实验的主题；北师大版、苏教版位置已预留，但目录未录入，不借用其他版本。
- **动态板书与时间轴**：逐步书写、重点高亮、字幕；播放、暂停、继续、上一步、下一步、跳到任意步、重新开始、0.5—2 倍速、查看完整过程。画面由当前步骤推导，暂停、跳转、回放不会错乱。
- **21 个数学演示（都能动手）**：一年级 拖苹果学加减法、图形分类（平面/立体）、欢乐购物街找零；二年级 分组乘法与平均分（含余数）、尺子测量、拖分针认识时间；三年级 分数（长条/圆）、周长与面积；四年级 量角器、平行与垂直、乘法分配律；五年级 小数乘法、天平与等式的性质（代入求值）、可能性真随机摸球；六年级 圆（切拼成长方形）、圆柱展开与圆锥体积、数轴与负数、打折与百分数、鸽巢问题、比例尺。
- **5 个科学实验**（v0.9.0 扩充到 11 个）：磁铁、水的三态变化、影子与太阳高度、串联/并联电路、摆的研究。每个都有目的、器材、步骤、可调参数、观察、解释、安全提醒和思考题，并说明屏幕模拟和真实实验的区别。
- **按年级调整**：低、中、高三个学段的句子长度、讲解节奏、公式呈现和练习难度都不同；演示只出现在适用年级，超纲内容必须标为课外拓展。
- **老师**：9 个中文快捷操作由离线规则老师处理（再讲一遍、换一种方法、生活例子、没听懂会放慢降难度、出题、错题分析、调难度）。可选“AI 老师”：家长在设置里填写自己的 OpenAI 兼容接口（如 DeepSeek）地址、模型和密钥后，可以直接提问；课堂数字由程序计算后作为事实交给 AI，AI 回复只显示为纯文本。
- **随堂练习**：选择、填空、判断、计算题由参数生成，答案用同一套计算独立核对；答错给出针对性提示和分步解析，可做同类变式；难度随答题自动调整。
- **导入资料**：可粘贴文字或打开 .md/.txt。逐行识别标题、题目和算式，能算的算式独立算出答案；识别不清（如 O 和 0 混淆）的要家长确认，超出年级或超出小学的内容会标出；每条都保留原文行号。
- **保存的数据**（都只在本浏览器）：`kaiqiao-class-log` 各课做题数和正确数；`kaiqiao-reduce-motion` 减少动态效果；`kaiqiao-ai` 仅在开启 AI 老师时保存地址、模型和密钥（可一键清除）。原有学情存档格式不变。
- **安全**：场景只接受结构化 JSON（`src/lib/lesson/scene.ts`），只允许登记过的演示和范围内的整数参数，不执行任何代码。
