## 使用

正式入口：[开窍在线练习](https://www.yanghat.cn/练习/) · [养习主站](https://www.yanghat.cn)

第一次使用请看[使用指南](USAGE.md)：按年级选择题库或互动课，三年级可从理解实验室开始；包含操作、计分、备份迁移和问题反馈方法。

下载新版发布包，解压后直接打开 `offline.html`。也可以把 `docs/` 部署到静态网页服务，访问 `index.html`。旧版下载包不会自动升级。

导航共 5 个标签：首页、课堂、题库、错题本、学情。

1. 首页选择练习年级；切换年级不会删除其他年级进度。
2. “题库”支持按知识点直接练习，提供基础/进阶两组及本年级搜索；也可切换原有闯关路线。首页可选“开始每日练习”或“开始闯关”。普通练习看完解析后点“下一题”；答错的题会安排同考点巩固。
3. “90 秒小挑战”是限时练习，“和窍窍比一比”的对手是电脑。限时模式会自动换题，可在错题本慢慢复习。
4. 错题本只显示当前年级；原题答对后移出。每个年级的章节独立解锁。
5. “课堂”按年级、学期、学科和教材选互动课；三年级的原创知识单元（理解实验室）也在“课堂”里（选三年级数学），首页三年级也有“去理解”入口。单元先读情境和讲解，操作实验，再做 8 题练习或 12 题自测，均逐题反馈。
6. “学情”汇总当前浏览器所有年级的已答题，支持文字报告和 JSON 备份。备份同时带上课堂练习记录和最近 60 天的每日题数；旧备份没有这两项时，恢复后它们保持本机原样。完成单元后还可导出家长建议。

## 数据与计分

- 不需要账号。记录仅保存在当前浏览器，不自动同步，也没有服务器收集孩子信息。
- 同一设备不同浏览器、网址或离线文件，可能使用不同的存储空间。更换前先导出备份，在新环境恢复。
- 恢复备份会替换所有年级的本机记录，先预览，再确认；不合并记录。新备份还会替换课堂练习记录和最近 60 天每日题数；不含这两项的旧备份不会动它们。
- 每次提交即保存答题、错题和技能统计。退出未完成练习不计通关、经验或打卡。
- 通关/每日整组完成，或限时结束且至少答过一题，才计打卡。未作答不算完成。
- 学情包含复习作答和未完成练习中的已答题，不等同于考试成绩。
- 浏览器禁用存储或存档损坏时会明确提示，不静默覆盖损坏的原存档。建议定期备份。
- 一个浏览器存档适合一名孩子；暂不提供多孩子账号隔离。

## 本地开发

使用 Node.js 24 或更高版本。

```bash
npm ci
npm run dev
```

```bash
npm run check       # 类型检查 + 回归测试 + 生产构建
npm run release     # 生成 docs/ 网站目录与 offline.html 单文件版
npm run test:smoke  # 原有冒烟 + 状态回归（先 npm run build；需要 Playwright Chromium）
npm run test:state  # 单独运行题目生命周期与 AI 竞态回归（同样先构建）
```

- `src/lib/math/`：题目、判分、存档校验和回归测试。
- `src/lib/lesson/`：互动课的计算、讲解脚本、随堂练习；`reference.ts` 是只给测试用的独立数学参考实现。
- `scripts/smoke.mjs`：浏览器冒烟测试，CI 每次运行；包含 `scripts/state-regression.mjs` 的状态回归。
- `src/store/math.ts`：练习状态、年级和结算。
- `src/components/math/`：首页、练习、错题、学情及电脑/手机自适应界面。
- `docs/`：可部署的构建产物；每次发布通过脚本重新生成。

## v0.13.0 质量强化与体验完善

这一版不加新课，重点是数学正确性、教学体验、自动化测试和数据安全。

- **数学正确性**：五节互动课（凑十法、条形统计图、多边形面积、小数除法、分数乘法）用独立的参考实现全量核对（BigInt 有理数、数论求循环节、质因数约分、鞋带公式算图形面积），不复用出题和演示时的计算函数。修正：
  - 小数除法竖式漏写商中间的 0（如 40.8 ÷ 4 只显示“商 1”“商 2”，容易被看成 1.2），现在逐行显示“0 ÷ 4 商 0”；
  - 除数是 1.7、2.8 这类数时找不到循环节（以前最多只除 8 步），现在一定能找到；循环节超过 6 位时说“循环节有几位”；
  - 凑十法 8 + 2 这类正好等于 10 的情况，原来说“加起来不满十”，现在说“正好凑成 10”；第一个数较小时（如 5 + 9）补充“看大数 9，分小数 5”的分法，不再把较小的数叫“大数”；
  - 条形统计图四种票数一样时，不再说“最多的比最少的多 0 票”；
  - 多边形面积的画法和公式共用同一组顶点，测试核对画出来的面积等于公式结果。
- **随堂练习**：分数乘法题目里的分数都用最简分数；假分数结果写成最简带分数（如 2又1/4）也判对；答错时更有针对性：小数除法“数字对了、小数点位置错了”、保留两位小数位数不对；分数乘法“分母相加”“没约分”“整数乘到分母上”“用了除法的方法”。
- **数据保护**：存档里个别记录损坏时，先把原始存档另存一份（写入并读回确认），再保留能识别的部分继续使用；整份读不懂时保持只读保护，学情页可下载原始存档。课堂练习记录、一周记录写入前同样先另存读不懂的原始内容，并保留不认识的条目，不再覆盖丢弃。
- **手机体验**：课堂里的按钮、参数滑块、步骤按钮、老师快捷按钮触控区域统一不小于 44 像素；多边形面积只在选梯形时显示“上底”参数。
- **测试与发布**：新增浏览器冒烟测试（`npm run test:smoke`，Playwright + 本地 vite preview，不访问外网），CI 每次运行：手机和电脑视口打开五节课、改参数核对结果、完成随堂练习看反馈、检查无运行时错误和横向溢出、旧版存档升级与损坏数据保护。
- **文档**：数学演示数量按代码实际统计为 25 个；修正使用指南序号和过时的“理解”入口、OCR 等描述。

## v0.12.0 两节新互动课：小数除法、分数乘法

- **五年级上册《小数除法：除数是小数怎么办》**（人教版新版五上第三单元、2012 版五上“小数除法”）：先看除数是不是整数——是整数就直接除，商的小数点和被除数的小数点对齐；是小数就把被除数和除数同时 ×10，商不变（被除数位数不够末尾添 0）。竖式每一步“几除以几、商几、余几”逐行显示，余数后添 0 的步骤会标出来；除不尽时显示循环小数、循环节和“保留两位小数”。动手模式用 ±0.1 / ±1 改被除数和除数，能除尽时自动给出验算。
- **六年级上册《分数乘法：求一个数的几分之几》**（人教版新版六上第二单元、2012 版六上“分数乘法”）：分数 × 整数演示“几个相同分数相加”，分子乘整数、分母不变；分数 × 分数用长方形面积模型，先竖着取几分之几，再横着取它的几分之几，数重叠的小格得到“分子乘分子、分母乘分母”，并提示先约分。动手模式可以直接点列、点行改分子。
- 两节课都有三种讲法（标准 / 换一种方法 / 生活例子）、三档随堂练习（答案独立重算核对，常见错误有针对提示）和生活例子；已挂到人教版新旧目录对应单元，导入资料时“除数是小数”“7.2÷0.4”“求 60 的 3/4”“分数乘分数”等会自动匹配到新课。数学演示现有 25 个。
- **直达链接**：`https://www.yanghat.cn/练习/?lesson=decimal-div&grade=5`、`?lesson=fraction-mul&grade=6` 可以直接打开某节课（主站课程卡片用的就是它），地址栏保持 `/练习/`，不改变已选年级和存档。
- **CI**：Check 工作流只在推送到 main、打开/更新 PR 和手动触发时运行，同一分支的新提交会取消旧的运行，不再因为旧分支逐文件提交而连发失败邮件。

## v0.9.0 科学实验扩充

新增 6 个科学互动实验，教科版科学目录扩展到三下、四上、四下、六上：

- **杠杆的科学**（六上·工具与技术）：调阻力、阻力点和用力点的格数，按“钩码数 × 格数”平衡条件计算用力，判断省力、费力；可直接点刻度移动用力点。
- **斜面的作用**（六上·工具与技术）：改变物重、斜面高和长，按理想斜面计算拉力，说明“坡越缓越省力、省力不省距离”。
- **声音的高低和强弱**（四上·声音）：改变拨钢尺的力度和伸出长度，看振幅和振动快慢的波形，区分响度和音调。
- **昼夜交替与地球自转**（六上·地球的运动）：拖动时间看北京在白天还是黑夜、太阳在哪个方向（按春分前后简化）。

- **绿豆种子发芽和生长**（三下、四下·植物的生长变化）：改变水分、光照和天数，看发芽条件和豆苗高度、叶色。

每个实验都有实验目的、器材、步骤、观察、解释、安全提醒、思考题和“虚拟模拟与真实实验的区别”，配随堂练习（独立重算核对）、生活例子和资料导入关键词。
